# TaskIT - Instrucciones del proyecto

## Objetivo
Crear una aplicación Android para organizar tareas académicas.

## Tecnologías
- Python
- Flet
- SQLite
- uv para gestionar dependencias

## Reglas de desarrollo
- Mantener el proyecto lo más sencillo posible.
- No agregar funcionalidades que no estén solicitadas.
- Utilizar SQLite para guardar los datos localmente.
- No implementar cuentas, servidores ni sincronización en la nube.
- Mantener una estructura de código organizada.
- Explicar los cambios antes de realizarlos.
- No modificar archivos innecesarios.
- Ejecutar pruebas después de implementar funcionalidades.

## Forma de trabajar
- Trabajar por etapas pequeñas.
- No avanzar a la siguiente etapa sin comprobar la anterior.
- Explicar qué hace el código y por qué.
- Mostrar los comandos necesarios para ejecutar y probar.
- Si hay varias soluciones, preferir la más sencilla.
- No actualizar dependencias sin justificarlo.
